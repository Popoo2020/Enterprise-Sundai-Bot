Q&A

Good questions. Straight answers.

What does private mean here?

Access and data handling are scoped for your organisation. The project identifies who processes content, which endpoints receive it, the storage region, supplier data-use terms and processing agreements. Private does not automatically mean EU-only or on-premises.

Is the complete AI chain end-to-end encrypted?

We specify TLS in transit and encryption at rest according to the architecture. We do not describe the complete path to an LLM as end-to-end encrypted without evidence that supports that claim.

What is a private AI assistant pilot?

One assistant, one ready-to-use knowledge source, one interface, one cloud provider, up to two user roles and up to ten pilot users. An enterprise AI chatbot or a document assistant is scoped around a real question set.

What does secure RAG implementation protect?

Secure RAG implementation addresses identity, retrieval permissions and source handling within the agreed architecture. Access-controlled retrieval must also account for vector stores, caches and exports; encryption alone does not establish permission boundaries.

Can we use Azure, AWS or Google Cloud?

An Azure private AI assistant, an AWS private AI assistant or a Google Cloud private AI assistant can be discussed for the chosen architecture. The base pilot selects one cloud; hosting region, supplier terms and retention are agreed before deployment.

Can the agent update systems as well as answer questions?

AI agent tool integration is included only when explicitly scoped. Human-supervised AI agents use limited permissions and approval for sensitive writes. A retrieved document or model answer does not grant authority to take action.

How do you check answer quality?

AI assistant evaluation uses representative questions, expected evidence, citation checks, permission tests and unsupported-answer refusal. RAG evaluation gives a baseline for a rollout decision; it does not promise that every answer will be correct.

Can we add website chat or WhatsApp later?

Website AI chatbot integration and WhatsApp AI integration require separate scope, platform access, data-processing terms and supplier costs. The initial pilot includes one agreed interface, with data retention rules and handover documentation.
