Q&A

Good questions. Straight answers.

Which Azure controls can you review?

A Microsoft Entra ID security review and Azure RBAC permissions review can examine agreed identities and resources. A Conditional Access baseline or Microsoft Entra PIM configuration review depends on licences, authorised changes and the selected scope.

Which AWS controls can you review?

An AWS IAM policy review looks at agreed policies and roles. An AWS IAM Identity Center review can examine workforce access within scope. STS and permission boundaries are considered where relevant; your team approves changes before activation.

Which Google Cloud controls can you review?

A Google Cloud IAM policy review can examine selected roles, bindings and conditions. A Google Cloud Privileged Access Manager review addresses agreed privileged-access controls. PIM and PAM are privilege-management services, not alternative names for RBAC.

What is included in monthly cloud security maintenance?

Monthly cloud security maintenance is a separately agreed service: scheduled permission and configuration checks, alert review, small changes and a report, within up to six working hours per month against an agreed backlog. Extra work requires an approved extension.

Does the package include emergency incident response?

No default on-call cover or 24/7 SOC is included. Initial evidence collection or specialist handoff may be agreed subject to availability. A response-time commitment needs suitable staffing, a separate on-call agreement and an SLA.

What access and decisions do you need from us?

Provide authorised access, an accurate asset inventory, a technical owner and a change approver. Agree licences, emergency contacts and recovery requirements. We scope the cloud IAM review and acceptance checks before work starts.
