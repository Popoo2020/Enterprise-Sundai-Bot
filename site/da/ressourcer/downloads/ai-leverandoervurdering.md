# Tjekliste til AI-leverandørvurdering

Brug tjeklisten som struktureret udgangspunkt ved indkøb, fornyelse eller implementering. Tilpas dybden til anvendelsen, de berørte personer, data og gældende ret.

## Formål og ansvar
- Hvilket forretningsproblem løser tjenesten?
- Hvem er forretningsmæssig og teknisk ejer?
- Hvilke brugere og berørte personer er omfattet?
- Hvad sker der, hvis tjenesten er utilgængelig eller giver et forkert resultat?

## Data og privatliv
- Hvilke data indsendes, genereres, lagres eller udledes?
- Hvor behandles og lagres data?
- Hvad er reglerne for opbevaring og sletning?
- Bruges kundedata til træning eller forbedring af modeller?
- Er underleverandører identificeret, og varsles væsentlige ændringer?

## Identitet og adgang
- Understøttes single sign-on, multifaktor og rollebaseret adgang?
- Hvordan styres og revurderes privilegerede roller?
- Hvordan opretholdes kundeadskillelse?
- Kan konti og adgang suspenderes og fjernes hurtigt?

## Model- og tjenestestyring
- Hvilke modeller og væsentlige komponenter anvendes?
- Hvordan kommunikeres og testes vigtige ændringer?
- Hvilke kendte begrænsninger og evalueringsresultater er dokumenteret?
- Hvordan reducerer leverandøren utilsigtet videregivelse og upassende output?

## Menneskeligt tilsyn og kvalitet
- Hvilke output kræver menneskeligt review før brug?
- Kan brugerne forstå begrænsninger og udfordre resultater?
- Hvilken test understøtter påstande om kvalitet, robusthed og fairness?
- Findes en sikker fallback, når kvaliteten er utilstrækkelig?

## Assurance og hændelser
- Hvilke rapporter, certificeringer og testbeviser er tilgængelige?
- Hvordan beskyttes og opbevares aktivitetsdata?
- Hvad er vilkårene for hændelsesvarsling og samarbejde?
- Hvordan registreres og korrigeres identificerede svagheder?

## Kontrakt, exit og kontinuitet
- Hvem ejer input, output, konfiguration og afledte data?
- Kan data og konfiguration eksporteres i et brugbart format?
- Hvordan dokumenteres sletning ved ophør?
- Hvilke kontinuitets- og exitordninger findes?
